# Portfólio de Agnaldo Peterson

Portfólio de dados, BI, automação e qualidade de software. A página destaca a migração de um relatório Power BI para Python e reúne projetos públicos de QA, desenvolvimento e visualização de dados.

[Abrir o portfólio](https://agnaldopeterson.github.io/)

## Desenvolvimento local

Abra index.html diretamente no navegador ou sirva a pasta com python -m http.server 8000. A página usa HTML e CSS e dispensa etapa de build.

Para editar o conteúdo, atualize index.html. Os estilos ficam em styles.css.
